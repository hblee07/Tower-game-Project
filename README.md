# Tower Defense Game Rule

# 게임 구성
- Stage 3개로 구성. 이전 스테이지 먼저 깨야하는 조건 X
- 각 스테이지마다 Wage 5개로 구성
- 스테이지 높아질수록 나오는 enemy와 boss의 수 많아짐

# 타이틀 화면 설명
- 원하는 스테이지 선택하여 플레이. 조건 없이 모든 스테이지 플레이 가능
- Ranking에서 각 스테이지 별 상위 20명의 점수 확인 가능
- Save 해놓은 파일이 있을 시, Continue 눌러 재시작 가능

# 기본 키 설명

## 게임 관련 기능
- S: 중간 상태 저장 (이후 Title 화면에서 재시작 시 해당 웨이브 초기 상태(골드, 타워 보존)로 돌아감)
- P 또는 Esc: 일시정지

## 타워 버튼 클릭 후 빈 칸 클릭: 설치

## 대상 타워 클릭: 선택 및 공격범위 표시
- U: 업그레이드 (업그레이드 시 타워 공격량만 증가)
- M: 대상 타워 선택 -> M -> 다른 merge 할 타워 선택 (Merge level 올라가면 타워의 공격량, 공속, 공격범위(Bomb Tower 제외) 모두 증가)
- Space: 스킬 사용 (타워 위 스킬 바가 100% 차면 파란색으로 뜸 --> 이때 사용 가능)
- Del: 해당 타워 판매하여 골드 얻음

# 보스 설명
- Rocket boss: 이동속도 매우 빠름, HP는 적음. Castle 도착 시 많은량의 피해 입힘
- Pacman boss: 죽을 때 자신과 가장 가까이에 있는 타워를 먹어서 없앰.
- Ghost boss: 이동속도 느림, HP 많음. 네 개의 서로 다른 이동속도 가진 보스가 생성됨

# 타워 설명
## Bomb Tower
- 공격 범위 내 랜덤한 위치에 폭탄 투하. 폭탄은 투하 후 0.2초 뒤에 터져 범위 내 적에게 피해 줌.
- 궁: 초거대 폭탄이 공격 범위 내 적 위치하는 곳에 투하됨

## Lightning Tower
- 공격 범위 내 가장 선두 적 공격. 연쇄적으로 전기가 뒤에 적까지 흐름(단, 뒤에 적이 어느정도 가까이 붙어 있어야함). 데미지 입히고 짧게 정지 시킴
- 궁: 공격량 높은 전기 공격, 더 길게 정지 시킴

## Thorn Tower
- 약한 데미지 입히고 이동속도 일정 시간동안 감소시키는 가시 공격
- 궁: 공격 범위 내 가시밭길 생성. 적의 이동속도 느려짐
